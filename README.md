# College Society Recruitment Portal

A centralized web application designed for university students to explore campus societies, take recruitment quizzes, find their ideal match, submit applications, and manage student onboarding seamlessly.

## Features

- **Society Directory & Details**: Browse through various university technical, cultural, and management societies with quick insights, roles, and requirements.
- **Find Your Society (Interactive Quiz)**: An interactive questionnaire that analyzes a student's interests, time commitment, and goals to instantly recommend the best-suited campus society.
- **Secure Authentication**: Built-in email/password user authentication powered by Supabase Auth to ensure personalized student sessions.
- **Application Portal**: Tailored application forms allowing students to apply for specific roles within their desired societies.
- **Role-Based Admin Dashboard**: A protected, secure administrative dashboard restricted exclusively to the portal administrator for reviewing incoming applications, tracking statistics, and filtering submissions by branch, year, or society.
- **Dark/Light Mode**: Fully responsive UI supporting both light and dark themes for a comfortable user experience.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Icons**: Lucide React
- **Backend & Database**: Supabase (PostgreSQL & Auth)

## Getting Started

### Prerequisites

Make sure you have Node.js installed on your machine.

### Installation & Setup

1. Clone the repository or open your workspace.
2. Install dependencies:
   ```bash
   npm install
   ```
